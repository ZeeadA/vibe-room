VIBE ROOM - iPhone install (GitHub Pages)

1. On github.com make a new PUBLIC repository (any name, e.g. vibe-room).
2. Upload everything in this folder (index.html, manifest.webmanifest, sw.js and the icons folder) to the repo root.
3. Repo Settings > Pages > Source: "Deploy from a branch", Branch: main, Folder: / (root). Save.
4. After a minute your page is at https://YOURNAME.github.io/vibe-room/
5. On the iPhone open that link in SAFARI > Share > Add to Home Screen > Add.
6. Open Vibe Room from the new Home Screen icon (not Safari) and add your songs there.

Notes
- Add songs from the Home Screen app, not Safari: they have separate libraries.
- Use the same link and repo name forever; changing it makes a new, empty library.
- To update: replace index.html in the repo. Your records are not touched.
